# 04 · 接入大模型:给机器人装上"大脑"

> 目标:在 WebUI 里添加一个大模型服务商,并在内置聊天页测试对话成功。
> 官方参考:`docs/zh/providers/start.md`、`docs/zh/providers/llm.md`。
> 对应源码:`astrbot/core/provider/`(Provider 管理器与各厂商实现)。

## 先理解:AstrBot 里大模型是"两层"配置

很多新手在这里困惑,先把这个模型讲清楚:

```
第 1 层:提供商来源(Provider Source)= "你连的是哪家服务商,用什么钥匙"
        例:DeepSeek、OpenAI、Ollama(本地)
        要填:类型(type)+ API Key(key)+ 接口地址(api_base)

第 2 层:模型(Model)= "具体用这家服务商下面的哪一个模型"
        例:deepseek-chat、gpt-4o-mini、qwen-plus
        要填:模型名(model)+ 绑定到第 1 层的哪个来源 + 是否启用
```

大白话:**先告诉 AstrBot "去哪家店、用什么钥匙",再告诉它 "点哪道菜"。**
对应到代码,`astrbot/core/provider/entities.py` 里 `ProviderMeta` 就是描述"模型"的数据结构,`provider_sources` 与 `provider` 是配置里两个数组。

## 用哪个服务商?(新手选型建议)

| 方案 | 花不花钱 | 难度 | 说明 |
|---|---|---|---|
| **DeepSeek** | 便宜,充值少即可 | 低 | 国内直连快,API 兼容 OpenAI 格式,新手首选 |
| OpenAI / Anthropic / Gemini | 付费 | 低 | 质量好,但国内网络可能需要代理 |
| **Ollama(本地)** | 免费 | 中 | 在你电脑上跑开源小模型,完全离线,不吃 API |
| 各类"网关"(硅基流动/302 等) | 便宜 | 低 | 一个 Key 用很多家模型 |

> 新手最顺滑的路线:**DeepSeek 或 Ollama**。

## 以 DeepSeek 为例,完整走一遍

### 第 0 步:拿到 API Key 和接口地址

1. 去 DeepSeek 开放平台(`platform.deepseek.com`)注册登录。
2. 左侧「API Keys」→ 创建一个 Key → 复制(形如 `sk-xxxxxxxx`)。
3. 记下它的接口地址(OpenAI 兼容格式):`https://api.deepseek.com/v1`。

> 请把 API Key 当成密码保管,不要发到群里/提交到 GitHub。

### 第 1 步:添加"提供商来源"

1. 打开 WebUI → 左侧「**模型提供商**」。
2. 点「新增提供商」(或"添加来源"),类型选择 **DeepSeek**(如果列表里有;没有就选 OpenAI,因为 DeepSeek 兼容 OpenAI 格式)。
3. 填入:
   - API Key:`sk-xxxx`(你的 key)
   - API Base URL:`https://api.deepseek.com/v1`
   - 模型列表一般会自动带出(也可以稍后手填)
4. 保存。

### 第 2 步:添加并启用"模型"

1. 在该来源下点「获取模型列表」(能拿到 `deepseek-chat` 等),或手动添加一个模型。
2. 填入/选择模型名,例如 `deepseek-chat`。
3. 确保该模型的**启用开关**打开。

### 第 3 步:在「配置文件」里把对话模型指定成它

1. 左侧进「**配置文件**」页。
2. 找到"对话模型 / LLM"相关配置项,点右侧选择按钮,选中刚才添加的来源+模型。
3. 点「保存配置」。

### 第 4 步:测试

进入左侧「**聊天**」页,发一句"你好",如果能收到正常回复,说明大脑已接通!🎉

## 常见字段速查

| 字段 | 含义 | 例子 |
|---|---|---|
| `type` | 服务商类型 | `deepseek` / `openai_chat_completion` |
| `key` | API Key | `sk-...`(Ollama 填 `ollama`) |
| `api_base` | 接口地址 | DeepSeek `https://api.deepseek.com/v1`;Ollama `http://127.0.0.1:11434/v1` |
| `model` | 模型名 | `deepseek-chat`、`gpt-4o-mini`、`qwen-plus` |
| `enable` | 是否启用 | 勾选 |
| `max_context_tokens` | 上下文上限 | 默认即可 |

> 小提示:用环境变量保护 Key(不写进配置文件):在 API Key 一栏填 `$环境变量名`,例如 `$DEEPSEEK_API_KEY`,并在启动前设置该环境变量(v4.13+ 支持)。

## 想先免费离线试试?用 Ollama

1. 去 ollama.com 下载安装 Ollama,然后在终端拉一个模型,例如:

```bash
ollama pull qwen2.5:7b
```

2. 回到 WebUI「模型提供商」,新增提供商,类型选 **Ollama**:
   - API Base URL:`http://127.0.0.1:11434/v1`
   - API Key:随便填 `ollama`
   - 模型:`qwen2.5:7b`
3. 在「配置文件」里选中它并保存,去聊天页测试。

> 更多说明见 `docs/zh/providers/provider-ollama.md`。

## 背后的代码(先混脸熟)

- 你保存的配置最终在 `data/cmd_config.json` 的 `provider_sources` / `provider` 字段。
- 启动后,`astrbot/core/provider/manager.py` 的 `ProviderManager` 读取配置、动态导入对应厂商类并实例化。
- 所有厂商实现都放在 `astrbot/core/provider/sources/` 下(如 `openai_source.py`、`anthropic_source.py`),它们都继承自 `astrbot/core/provider/provider.py` 里的抽象基类 `Provider`。
- 运行时真正"发请求给大模型"的入口,通常是你调用 `provider.text_chat()` / `text_chat_stream()`。

现在不用看懂这些,只要记住:**加一个模型 = 配一个来源 + 配一个模型 + 在配置文件里选中它。** 笔记 09 会看到它被调用。

## 📌 小练习

1. 接好一个能用的模型,在「聊天」页成功对话。
2. 去 `data/cmd_config.json` 里找到你刚添加的 provider 配置段,读一读字段。
3. 想一个问题:如果给机器人设定了"人格设定"(人设),回复会变吗?去「人格设定」页随便试试(改完记得恢复)。
