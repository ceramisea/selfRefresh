# 03 · 认识 WebUI 控制台

> 目标:登录控制台后,能说出左侧导航每个页面大概干嘛;知道配置最终存在哪。
> 对应源码:`dashboard/`(Vue 前端)、`astrbot/dashboard/server.py`(WebUI 后端服务)。

## 登录

浏览器打开 `http://localhost:6185`:

- 用户名:默认 **`astrbot`**
- 密码:首次启动若没设置,使用**启动日志里打印的随机初始密码**(用户名下方一般也有提示)。登录后请尽快修改密码。

> 也可以用环境变量预设初始密码(可选,进阶):
> 启动前设置 `ASTRBOT_DASHBOARD_INITIAL_PASSWORD=你的密码`,再 `uv run main.py`。
> 忘记密码可参考附录 FAQ。

## 最重要的心智模型:配置存哪里?

你在网页上做的所有配置,最终都会写进磁盘上的一个 JSON 文件:

```
data/cmd_config.json     ← 整个 AstrBot 的"大脑配置文件"
```

- `data/` 目录在你启动 AstrBot 的目录下(AstrBot-master/data),第一次运行自动生成。
- 这个文件是**机器可读的配置**,平时尽量用 WebUI 改,不要手改(改坏了可能启动失败)。
- 但理解它的存在很重要——后续看代码时,`astrbot/core/config/` 就是读写这个文件的模块。

相关的其他数据目录(也在 `data/` 下):

| 目录 | 存放内容 |
|---|---|
| `data/config/` | 部分配置文件 |
| `data/plugins/` | 安装的第三方插件 |
| `data/temp/` | 临时文件 |
| `data/knowledge_base/` | 知识库数据 |
| `data/site-packages/` | 插件依赖的第三方包(隔离安装) |

> 提醒:这些都在源码目录下,升级/删源码前记得备份 `data/`。

## 控制台与代码的对应(心里有张图)

你在"机器人"页加一个 QQ 机器人 → 本质是在 `cmd_config.json` 里加了一段 `platform` 配置 → 启动时 `PlatformManager` 读到它 → 去 `astrbot/core/platform/sources/` 找到对应适配器并启动。

你在"模型提供商"页加一个 DeepSeek → 本质是加了一段 `provider_sources` + `provider` 配置 → 运行时 `ProviderManager` 按配置调用对应 API。

**结论:WebUI 只是配置的"图形化编辑器",真正干活的是一套按配置驱动的 Python 管理器。** 这正好衔接笔记 07 的代码地图。

## 📌 小练习

1. 成功登录控制台。
2. 点开「配置文件」页面,找到"对话模型 / 唤醒前缀"相关字段,只看不改。
3. 打开 `AstrBot-master/data/cmd_config.json`,对照 WebUI 里看到的配置项,找到几处对应关系(比如 `dashboard.username`)。不要修改文件。
4. 点开「聊天」页面,随便聊两句——此时还没有接大模型,所以应该还不能正常回答,这很正常,下一步就解决。
