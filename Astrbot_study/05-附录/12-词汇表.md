# 12 · 词汇表

> 阅读源码和文档时遇到术语,回来查这里。按拼音/字母序排。

## A

- **AstrMessageEvent(消息事件)**:AstrBot 内部统一的"一封信",不管来自哪个平台都被翻译成它。携带消息内容、发送者、平台信息,并提供了 `send`(回复)、`plain_result`(纯文本回复)、`request_llm`(请求大模型)等方法。全框架的数据核心。
  `astrbot/core/platform/astr_message_event.py`

- **Agent(执行器/智能体)**:负责"怎么用大模型完成任务"的组件。本地 Agent 会进入"思考 → 可能调用工具 → 再思考"的循环。
  `astrbot/core/agent/`、`astr_agent_run_util.py`

- **async/await(异步)**:让程序在等待网络等耗时操作时去处理别的任务的写法。`async def` 定义协程,`await` 等待一个异步结果。

## C

- **ChatUI**:AstrBot 内置的网页聊天界面,不需要外部 IM 也能在浏览器里和机器人对话。
- **Context(插件上下文)**:启动时把各种管理器打包给插件的一个对象,插件通过它调用 AstrBot 的能力。
  `astrbot/core/star/context.py`
- **Cron(定时任务)**:按计划周期执行的任务,如"每天早上 8 点发早报"。`astrbot/core/cron/`
- **cmd_config.json**:整个 AstrBot 的配置文件(JSON),位于 `data/cmd_config.json`,WebUI 的配置最终写到这里。

## D

- **Dashboard**:WebUI / 管理面板 / 网页控制台,默认 `http://localhost:6185`。
- **Decorator(装饰器)**:`@xxx` 开头的语法,把下面函数/类"登记"或"附加功能"。见笔记 06。

## E

- **EventBus(事件总线)**:从队列取消息事件、分发给对应流水线调度器的枢纽。
  `astrbot/core/event_bus.py`
- **EventType(事件类型)**:系统定义的一类事件枚举,如"收到消息 AdapterMessageEvent""请求 LLM 前 OnLLMRequest"等,插件可挂钩子。
  `astrbot/core/star/star_handler.py`

## F

- **filter(过滤器/指令装饰器)**:插件里用来声明"我这个函数响应什么消息"的东西,如 `@filter.command("hello")`、`@filter.regex(...)`。
  `astrbot/core/star/filter/`

## H

- **Handler(处理函数)**:插件类里真正处理消息的函数,统一签名 `async def xxx(self, event: AstrMessageEvent)`。

## I

- **i18n(国际化)**:让界面/文案支持多语言。AstrBot 内置了对中英文等多语言的支持。

## K

- **Knowledge Base(知识库)**:上传文档给机器人,让它能基于你的资料回答。`astrbot/core/knowledge_base/`

## L

- **LLM(Large Language Model,大语言模型)**:如 GPT、DeepSeek、Qwen、Gemini 等 AI 模型。
- **logger**:日志对象,`logger.info("...")` 打印信息到日志,方便排查。

## M

- **MCP(Model Context Protocol)**:一种让 AI 连接外部工具/数据的标准协议。`astrbot/core/agent/mcp_client.py`
- **MessageChain(消息链)**:一串消息组件(文本/图片/@人等)组成的一条回复。
  `astrbot/core/message/message_event_result.py`
- **metadata.yaml**:插件文件夹里的"身份证",包含 name/desc/author/version,是插件被识别的前提。

## O

- **OneBot v11**:一种聊天机器人协议标准;AstrBot 通过 `aiocqhttp` 适配器对接 NapCat 等 OneBot 实现。
- **Onion model(洋葱模型)**:流水线各 Stage 层层嵌套、可插拔的处理模型。

## P

- **Pipeline(流水线)**:消息从进来到回复经过的一串处理关卡(Stage)。
  `astrbot/core/pipeline/`
- **Platform(平台适配器)**:连接某个 IM(QQ/Telegram…)的"耳朵和嘴巴"。所有适配器在 `astrbot/core/platform/sources/`。
- **Plugin / Star(插件)**:给 AstrBot 加功能的代码包,继承 `Star` 类。官方自带的叫"内置 Star"。
- **Provider(模型提供商)**:封装某家大模型服务商的调用,如 OpenAI、DeepSeek、Ollama。`astrbot/core/provider/`
- **Provider Source(提供商来源)**:Provider 的"第一层",描述服务商地址与 API Key。
- **ProviderType(提供商类型)**:能力类型,如对话 `chat_completion`、语音转文字 `speech_to_text` 等。

## R

- **Reload(重载)**:不重启 AstrBot,重新加载插件使代码改动生效。

## S

- **Sandbox(沙箱)**:隔离的执行环境,安全地运行代码/命令,防止影响宿主机。`astrbot/core/computer/`
- **Skills(技能)**:一类给 Agent 使用的标准化"说明书式"技能(类似插件的轻量扩展)。
- **Stage(关卡)**:流水线中的一环,如唤醒检查、内容安全、发送回复。
- **STT/TTS**:语音转文字(Speech-to-Text)/ 文字转语音(Text-to-Speech)。
- **Star 见 Plugin。**

## U

- **uv**:新一代 Python 包/项目管理工具,本项目官方推荐。比 pip 快、会自动建虚拟环境。
- **unified_msg_origin**:消息事件上的"来源标识"(哪个平台/会话),EventBus 靠它路由。

## V

- **venv / Virtual Environment(虚拟环境)**:为单个项目隔离的 Python 环境,避免依赖互相污染。uv 默认会为项目建一个。

## W

- **Waking(唤醒)**:判断一条消息是否在"叫"机器人(私聊、@、指令前缀等),只有被唤醒的消息才会进一步处理。
- **WebUI 见 Dashboard。**

## Z

- **注册表 / 注册(Register)**:通过 `@register_xxx` 把类登记到一张 dict,配置里写某个名字就能找到它并实例化。AstrBot 平台/模型/插件大量使用这种模式。
