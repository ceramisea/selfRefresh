## 下一阶段:四个可选方向

按兴趣选,不必全做:

### 方向 A:把 Python 本身补扎实
你的短板主要在基础语法之外。推荐按顺序:
1. 类与面向对象(继承、`super()`)——官方教程的 Classes 一章
2. 装饰器原理(`functools.wraps`、带参数装饰器)
3. `async/await` 进阶:任务 `asyncio.create_task`、协程如何并发
4. 类型标注进阶:`TypedDict`、`Protocol`、`dataclass`

> 实践妙招:**在 AstrBot 源码里找对应例子**。装饰器看 `core/star/register/`,异步看 `core/event_bus.py`,类设计看 `core/platform/manager.py`。

### 方向 B:深入 AstrBot 的某个"器官"
| 想搞懂 | 去读 | 官方文档(本地) |
|---|---|---|
| Agent 怎么思考、调工具 | `core/agent/`、`core/astr_agent_run_util.py`、`core/tools/` | `docs/zh/use/function-calling.md`、`docs/zh/use/agent-runner.md` |
| 会话记忆怎么存、怎么压缩 | `core/agent/context/`、`conversation_mgr.py` | `docs/zh/use/context-compress.md` |
| 知识库怎么检索 | `core/knowledge_base/` | `docs/zh/use/knowledge-base.md` |
| 定时任务 | `core/cron/` | `docs/zh/use/command.md`(含 cron 指令) |
| MCP / 外部工具 | `core/agent/mcp_client.py`、`api/web.py` | `docs/zh/use/mcp.md` |
| 插件高级 API | `core/star/`、`astrbot/api/` | `docs/zh/dev/star/plugin-new.md` |

### 方向 C:改源码 / 参与开源
如果想给 AstrBot 提 PR:
1. 先读根目录 `AGENTS.md`(开发约定:KISS、Google 风格 docstring、用 `ruff` 格式化、commit 用 conventional commits)。
2. 本地跑起来 `ruff format .` / `ruff check .`。
3. 从 `good first issue`(GitHub Issues)入手。
4. 开发时改动前后端 API,需要重新生成前端客户端:见 `AGENTS.md`。

### 方向 D:造一个"自己的机器人"项目
把学到的东西用起来,选一个小目标:
- 给机器人加"每日天气定时播报"(定时任务 + 插件)
- 做一个"基于自己笔记回答问题"的私人知识库机器人(知识库)
- 给插件加一个"联网搜索"工具(MCP / 工具调用)
