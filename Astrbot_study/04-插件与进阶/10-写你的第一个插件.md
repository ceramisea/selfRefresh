# 10 · 写你的第一个插件(Star)

> 目标:亲手写一个能响应 `/hello` 指令的插件,并在 AstrBot 里加载成功。
> 官方参考:`docs/zh/dev/star/plugin-new.md`、`docs/zh/dev/star/guides/simple.md`。
> 官方最小模板仓库:[Soulter/helloworld](https://github.com/Soulter/helloworld)。

## 插件 = 放在 `data/plugins/` 下的一个文件夹

一个最简单的插件是这样的结构:

```
data/plugins/
└── helloworld/
    ├── metadata.yaml     # 插件的"身份证"(必填)
    └── main.py           # 插件代码(文件名必须是 main.py)
```

> 回忆笔记 07/08:启动时 `PluginManager`(`core/star/star_manager.py`)会扫描 `data/plugins/` 目录,把每个合法插件加载进来。你写好文件夹 → 在 WebUI 点"重载插件"即可生效,**不需要重启 AstrBot**(热重载)。

## 第一步:建文件夹和 metadata.yaml

在 `AstrBot-master/data/plugins/` 下新建文件夹 `helloworld`,在里面创建 `metadata.yaml`:

```yaml
name: helloworld
desc: 我的第一个 AstrBot 插件
author: 你的名字
version: 1.0.0
```

> `metadata.yaml` 是 AstrBot 识别插件的依据,必填字段一般就这四个:`name` / `desc` / `author` / `version`。

## 第二步:写 main.py(核心代码)

在 `helloworld/` 里新建 `main.py`,内容如下(参考官方最小示例):

```python
from astrbot.api.event import filter, AstrMessageEvent
from astrbot.api.star import Context, Star
from astrbot.api import logger


class HelloWorldPlugin(Star):
    """我的第一个插件:回复 /hello"""

    def __init__(self, context: Context):
        super().__init__(context)

    # 注册一个指令:用户发 /hello 就会触发下面的函数
    @filter.command("hello")
    async def hello(self, event: AstrMessageEvent):
        """这是一个 hello 指令(会显示在插件说明里,建议写)"""
        user_name = event.get_sender_name()      # 发送者的昵称
        logger.info(f"触发了 /hello,来自 {user_name}")  # 打印到日志
        yield event.plain_result(f"Hello, {user_name}! 👋")  # 回复纯文本
```

逐行解释(对照笔记 06 的知识):

| 代码 | 含义 |
|---|---|
| `from astrbot.api.event import filter, AstrMessageEvent` | 从公开 API 层导入"过滤器装饰器"和"消息事件类型" |
| `class HelloWorldPlugin(Star)` | ★ 插件类必须**继承 `Star`**;AstrBot 会自动发现它(不需要额外注册) |
| `def __init__(self, context: Context)` | 构造时拿到 `Context`(插件"工具包",可调用各种 API),记得 `super().__init__(context)` |
| `@filter.command("hello")` | ★ 注册指令:把下面这个函数登记为"处理 `/hello` 指令"的 handler |
| `async def hello(self, event: AstrMessageEvent)` | handler 统一签名:`(self, event)`;异步函数(因为要等网络) |
| `event.get_sender_name()` | 从消息事件里取"发送者昵称" |
| `yield event.plain_result(...)` | 产生回复结果:发一条纯文本消息 |

> 关键点:handler **前两个参数必须是 `self` 和 `event`**;回复用 `yield event.plain_result("文本")`。

## 第三步:加载插件并测试

1. 确保 AstrBot 正在运行(`uv run main.py`)。
2. 打开 WebUI →「**插件**」页 → 应该能看到 `helloworld`。
3. 如果没看到,点插件页右上角的「**重载插件**」(或 `...` 菜单里的重载)。
4. 在你接好的平台里,给机器人发:

```
/hello
```

机器人应回复:`Hello, 你的昵称! 👋`

> 没接平台?用内置「聊天」页(ChatUI)也能测;或临时用 WebUI 里的对话入口。

## 想再进一步?试试这些"装饰器"

插件的能力都来自"装饰器 + handler"这个套路:

```python
@filter.command("echo")                      # 1. 指令触发:发 /echo xxx
async def echo(self, event: AstrMessageEvent):
    yield event.plain_result(f"你说的是: {event.message_str}")

@filter.regex(r"^你好$")                      # 2. 正则触发:发"你好"就命中
async def hello_regex(self, event: AstrMessageEvent):
    yield event.plain_result("你好呀!")

@filter.command_group("admin")                # 3. 指令组:/admin add xxx
async def admin(self, event: AstrMessageEvent):
    yield event.plain_result("admin 组指令")
```

对应代码位置(想深入时看):

- 各种装饰器:`astrbot/core/star/register/star_handler.py` 和 `astrbot/api/event/filter` 里导出的 `filter`
- `Star` 基类:`astrbot/core/star/base.py`
- 过滤器实现:`astrbot/core/star/filter/`
- 事件对象上还有 `request_llm`、`send` 等能力,可看 `core/platform/astr_message_event.py`

## 注意事项(官方开发原则摘录)

- 插件的**持久化数据**存到 `data/` 下,不要存在插件自己目录里(更新插件会被覆盖)。
- 网络请求用异步库(`aiohttp`/`httpx`),**不要用 `requests`**(会卡住事件循环)。
- 插件代码报错时,WebUI 插件页会提示,可点"尝试一键重载修复"。
- 插件要发到插件市场与人分享时,再看 `docs/zh/dev/star/plugin-publish.md`。
