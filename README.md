## 📖 项目一：Astrbot_study —— AstrBot 学习路径

**AstrBot** 是一个开源的一体化 Agent 聊天机器人平台，能对接主流即时通讯软件，帮助你快速搭建个人 AI 陪聊、智能客服或自动化助手。本项目以一套**循序渐进**的笔记，带你从零上手并最终看懂它的源码。

- **适用人群**：会 Python 最基本语法（变量/循环/函数/列表/字典）、但还没系统学过面向对象和异步的人。
- **学习目标**：① 成功运行 AstrBot → ② 接入大模型和聊天平台 → ③ 看懂核心代码如何流转 → ④ 尝试写插件。
- **配套源码**：目录同级 `AstrBot-master/`（v4.28.0-beta.1，Python ≥ 3.12）。

## 📚 项目二：qqbot-study —— 亚托莉 QQ 陪伴机器人 · 源码学习手册

**亚托莉 QQ 陪伴机器人 (Atri QQ Bot)** 是一套完整的 AI 陪伴机器人工程：基于 OneBot/NapCat 协议接入 QQ，用 LLM 驱动人设回复，内置**分层记忆 + RAG 语义检索、Function Calling 工具系统、独立语音/歌声服务、桌面宠物与 Web 管理面板**。

这是一**个单 HTML 文件**的源码学习手册，打开即可在线阅读：把「一条私聊消息如何变成一句亚托莉回复」的完整链路讲清楚，再深入到记忆、工具、语音等模块。**依据源码 v0.3**（对应同级 `AI-girlfriend-QQ-main/`）。

- **一句话定位**：不是单文件脚本，而是多服务系统 —— NapCat 负责登录 QQ 并转发消息，Python 主服务负责理解与回复，独立语音服务负责 TTS/ASR，WebUI 负责运维，桌宠把一切包装成桌面上的小宠物。
- **规模**：源码 ≈4.6 万行，5 个核心包，337 个测试用例通过；监听端口 8765 / 8787 / 8790 / 6099。
- **学习建议**：先跑通「一条私聊消息 → 一句亚托莉回复」的链路（04→05），再逐个深入记忆（06）、工具（07）、语音（10）。
